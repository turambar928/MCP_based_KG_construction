# 人工标注实验完整包

本包供项目负责人统一保管，包含两位标注者和协调员的全部材料。

## 如何发放

1. 将 `单独发放压缩包/标注者_A.zip` 发给标注者 A。
2. 将 `单独发放压缩包/标注者_B.zip` 发给标注者 B。
3. 协调员材料由负责人保管，不发给标注者。

也可以分别发放 `annotator_A/`、`annotator_B/` 文件夹；务必保留目录内全部文件，让离线页面能打开详细说明。

每位标注者独立完成 200 条输入差异和 200 条实际修改。标注者目录内有离线 HTML 页面、Excel 表格及中文说明；二选一填写并交回最终 JSON 或 XLSX。标签模板未改动。

详细判断规则见 `ANNOTATOR_GUIDE_zh.md`，收回、合并、裁决和统计流程见 `COORDINATOR_GUIDE_zh.md`。统计命令在原项目仓库根目录运行；填写页面本身不需要网络或 Python。

`manifest.json` 保留原交付文件和冻结样本的校验信息。本次只合并文件，不重新抽样，也不生成或修改人工标签。
