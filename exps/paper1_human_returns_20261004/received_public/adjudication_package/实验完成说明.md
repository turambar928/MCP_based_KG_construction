# Paper 1 人工复核实验完成记录（2026-10-04）

## 流程与校验

两位有计算机科学背景、具备足够中文阅读能力的标注者，均阅读练习示例后，彼此不交流地各自完成相同的 400 条正式标注（D、E 各 200）。这些人员与流程信息由作者在本次对话中确认；文件本身不能证明。两份原始 JSON 的版本、ID、标签与理由已通过仓库原校验。

第三位人员通过离线问卷裁决 154 条至少有一项分歧的条目（D 76、E 78），其中采用 A 的判断 30 条、B 的判断 124 条；未改动两人的原始标签。原先双方完全一致的 246 条保留一致标签。问卷没有预填上一轮 AI 候选标签。一个 E 操作可接受性判断保留 U。

原评分器 `exps/paper1_human_review/process_returns.py score` 已成功验证 400 条的不可变上下文／独立标签哈希、裁决完整性，并输出总体与分配置统计。完成版 CSV 与原始裁决包 ZIP 比较，除最后三个裁决列外所有字段逐项一致。回答和文件 SHA-256 见 `裁决流程与哈希.json`。
