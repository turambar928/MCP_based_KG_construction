\abstract{
从文本构建的知识图谱常有事实缺失、取值错误和三元组重复。修复需要找出这些错误，用约束引导修改，并选择有用的编辑。我们提出一个框架，将多尺度质量评估、约束驱动修复和尺度感知路由结合起来。局部、图和来源检查形成共享的评估概况。来源与字段约束引导图生成，并过滤候选三元组。神经路由器根据评估概况为候选编辑赋予权重。选择器在图的副本上检查每项编辑，在图约束下比较质量收益和成本，并在接受修改后更新评估概况。实验覆盖中文政务、金融和环境记录、收据及合同，并包含组件测试和人工评价。主流程修复了 98\% 的注入缺陷。在收据任务中，来源行提示使 F1 比 简单流程 高 4.76 个百分点。评价同时记录恢复的事实和保留的原正确事实，展示各修复阶段如何影响输出图。
}
\keywords{知识图谱修复，源文本，字段检查，文档抽取}
