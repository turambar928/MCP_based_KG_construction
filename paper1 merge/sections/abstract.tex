\abstract{
Knowledge graphs built from text often contain missing facts, wrong values,
and repeated triples. Repair needs checks that find these errors, constraints
that guide changes, and a way to choose useful edits.
We present a framework that links multi-scale quality assessment,
constraint-driven repair, and scale-aware routing.
Local, graph, and source checks form a shared assessment profile.
Source and field constraints guide graph generation and filter the proposed
triples. A neural router uses the profile to weight candidate edits.
The selector checks each edit on a graph copy and compares its quality gain
and cost under graph bounds. It updates the profile after each accepted change.
Tests cover Chinese government, finance, and environment records, receipts,
and contracts, with component tests and human review.
The main pipeline repairs 98\% of added defects.
On receipts, source-line hints raise F1 over Simple Pipeline by 4.76 points.
The evaluation tracks recovered facts and correct facts kept, showing how
each repair stage affects the output graph.
}
\keywords{Knowledge Graph Repair, Source Text, Field Checks, Document Extraction}
