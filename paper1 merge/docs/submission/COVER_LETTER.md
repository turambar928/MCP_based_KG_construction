# DMKD cover letter — author-review draft

Dear Editors,

Please consider “Repairing Document Knowledge Graphs with Source Text and Field Checks” for publication as a research article in *Data Mining and Knowledge Discovery*.

The paper joins graph checks with repair using source text and field constraints. An assessment profile records local, graph, and source errors. The main path generates field values and filters the output. A scale-aware selector also compares edits on graph copies, using quality gains, costs, and graph bounds. Shared prompts and scores before and after filtering show what each step changes.

The tests cover added defects, model-built graphs, receipts, and contracts. Diagnosis + Gate repairs 98.00% of added defects and raises F1 from 87.99% to 92.48% on model-built graphs. Source-line hints raise receipt F1 over Simple by 4.76 points (95% CI: [2.50, 7.26]). Two reviewers check 200 reference differences and 200 system edits. The paper reports field recovery, facts kept, request costs, and human edit acceptance.

The work connects an assessment profile, repair choices, and output checks. The repository shares code, prompts, sample lists, model outputs, scoring scripts, and human-review totals: https://github.com/turambar928/MCP_based_KG_construction. The merged manuscript is in the “paper1 merge” folder.

Thank you for considering the manuscript.
