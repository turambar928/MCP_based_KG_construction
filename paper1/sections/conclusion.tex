\section{Conclusion}
\label{sec:conclusion}

We repair document graphs with source text and field checks.
The method cleans the input, asks a model for a complete graph, and filters
the triples. Shared prompts and scores before and after filtering show
what each step changes.

Diagnosis + Gate repairs 98.00\% of the added defects and raises F1 from
87.99\% to 92.48\% on model-built graphs. Field copying recovers every
reference in the Chinese records. Source-line hints raise receipt F1 by
4.76 points over Simple. The full index and anchors alone have the same
mean F1 in the later test. Indexed contract repair reaches 44.84\% F1,
compared with 46.76\% for the input. Its difference from fresh extraction
is 0.72 points (95\% CI: $[-4.80,6.48]$).
Source and document-ID checks remove unwanted triples.
Error reports lower mean F1 in the matched tests, and the default learned
selector scores below equal weights on model-built inputs.

Human review finds input errors in 95/200 reference differences.
Reviewers accept 134/199 edits across five settings, with one uncertain edit.
These results give clear targets for better repair: select the right value
for each field, keep correct input facts, and check the final graph.
