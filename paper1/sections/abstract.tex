\begin{abstract}

Constructing knowledge graphs (KGs) from text introduces structural, logical, and semantic defects that require different repair mechanisms. We propose a constraint-driven multi-scale framework that combines entity-level preprocessing, graph-level validation, source-grounded contextual completion, and a final constraint gate. A lightweight router uses the resulting diagnostic profile to avoid unnecessary repair calls. We evaluate the framework on a reproducible paired benchmark built from government, finance, and environmental documents. Its held-out set contains 225 corrupted document graphs, 450 manifested defects from six classes, and a clean target for every case. Under shared inputs and a shared base model, the framework repairs 98.00\% of defects, preserves 99.32\% of clean facts, and obtains 99.17\% triple F1 and 93.33\% exact graph match. Direct LLM repair reaches 92.44\% defect repair and 95.20\% triple F1; a two-call ReAct-style agent reaches 89.11\% and 92.13\%, respectively. Paired McNemar tests favor the proposed method over both model-backed baselines. Ablations show that contextual reasoning supplies most recovery, while structural preprocessing and constraint gating reduce collateral edits. An independent Gemma judge reproduces gold validity with Spearman $\rho=0.807$, and a controlled TNEWS comparison shows behavior comparable to Neo4j LLM Knowledge Graph Builder. All case-level predictions, manifests, and statistical outputs are archived for reproduction.
	
\keywords{Knowledge Graph, Quality Assessment, Large Language Models}

\end{abstract}
