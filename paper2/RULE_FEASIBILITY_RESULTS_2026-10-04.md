这是一项受控参考恢复开发研究，不是自然错误评测，也不是新的 RL 训练实验。与旧两轮同时改变了文档和提示，不能用新旧差值单独证明提示格式的效果。

## 3. 修复表现

F1、参考保留率、获取包数按 10 个文档对取平均；移除和损失为全批总数。

|策略|F1|参考保留率|移除注入项 / 28|损失参考事实 / 226|平均获取包数|
|---|---:|---:|---:|---:|---:|
|停止，不编辑|94.02%|100.00%|0|0|0.0|
|两种策略全部获取后修复|96.63%|98.14%|17|4|4.0|
|另外三种双策略获取／修复顺序|96.63%|98.14%|17|4|4.0|
|仅 deletion|96.63%|98.14%|17|4|2.0|
|仅 augmentation|94.24%|100.00%|1|0|2.0|
|均匀随机可行动作，含停止|95.58%|100.00%|8|0|2.1|

完整流程比停止提高 **2.61 个百分点**，文档对 bootstrap 的描述性 95% 区间为 **[0.81, 4.30]**。这是开发诊断区间，不是独立确认性优势检验。保留率 98.14% 是文档对平均，不能用全批的 222/226 直接替代。

四种双策略流程与仅 deletion 的最终图相同。仅 augmentation 移除的 1 个注入项已经包含在 deletion 的 17 个之中：deletion 独有移除为 16 个，augmentation 独有移除为 0 个。因此，这批数据支持 deletion 的有效覆盖，没有支持 augmentation 带来额外修复。

随机策略每对只使用一个冻结种子，其较高参考保留率不能解释为随机调度普遍更安全，也不能作为已完成的学习策略对照。

## 4. 来源规则究竟发挥了什么作用

在完整流程每次实际删除之前，临时去掉来源矛盾规则，保持该时刻其他规则及图状态不变，再检查违规标记。只有不再被标记的记录才计为“来源规则必要”，避免把类型规则本来就能完成的删除重复归功于来源规则。

- 文档对 4：来源规则必要地移除 1 个注入项，没有对应参考损失。
- 文档对 9：来源规则必要地移除 2 个注入项，同时造成 2 条参考事实损失。
- 总计：来源规则在两个文档对中必要地移除 **3 个注入项**，也必要地删除 **2 条参考事实**。文档对编号从 0 开始。

这说明来源规则已具备实际编辑作用，但来源证据检查还不能保证编辑正确。该计算是同一编辑状态的局部机制诊断，不是重新生成候选或完整去来源模块实验。涉及的记录 ID 和引用哈希已保存，可供作者之后核查；没有由模型代填人工结论。

## 5. 为什么没有进入训练

|预先冻结的条件|本批结果|结论|
|---|---|---|
|至少 36/40 响应符合格式|39/40|通过|
|同一确定性策略提高 F1、平均保留率至少 99%、来源必要修复覆盖至少 2 对|完整流程提高 F1、来源覆盖 2 对，但保留率仅 98.14%；仅 augmentation 不满足来源覆盖|未通过|
|两种单策略各有安全的独有注入项移除|augmentation 独有为 0；deletion 有 4 条参考损失|未通过|
|安全 oracle 质量空间至少 0.5 个百分点，或满足安全同质量节省条件|安全 oracle F1 96.75%，比最强固定策略高 0.12 点；另有一对不存在匹配其 F1 的安全路径|未通过|

最强固定策略为仅 deletion。安全 oracle 要求每对参考保留率至少 99%，然后利用评分标签事后挑选最优可行路径。它的 96.75% 不是可部署策略的实测成绩，也不能用来宣称已经节省在线调用。

同质量安全路径相对仅 deletion 的获取包节省依次为 `[0, 2, 0, 0, 0, 0, 无可行路径, 0, 0, 2]`。不能删除无可行路径的那一对后，给出一个看起来更好的平均节省结果。

因此没有启动 DDQN、DQN 或任何正式扩训；旧两轮协议及旧正式 runner 的阻断状态保持不变。

## 6. 实际调用成本与服务状态

- 40 次请求，HTTP 200 为 40 次；返回模型名全部匹配指定 Gemma。
- 输入 255,391 tokens，输出 58,346 tokens，总计 313,737 tokens，来自服务返回 usage。
- 测量的请求耗时总和 551.96 秒，均值 13.80 秒，中位数 15.23 秒，最大 25.55 秒。
- 耗时不包含每次请求前的 3 秒间隔及后续评分／编译；未推算货币费用。

本批说明服务在此次采集期间可用，不能保证之后持续稳定。离线策略的“2 包／4 包”与实际预采集的 40 次请求是不同口径，未将离线少取包直接写成在线省钱。
