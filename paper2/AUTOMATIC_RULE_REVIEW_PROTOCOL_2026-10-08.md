# Paper2 自动规则核验开发协议（2026-10-08）

版本：`episode-scoped-automatic-review-20261008-v1`。本协议在模型请求前冻结，不覆盖 10-04 的协议、失败门槛、响应及空独立 registry。保持 RL 协同优化与双策略生成主线；不启动训练。

## 问题与数据

检验自动核验能否减少生成规则的参考事实误删，并保留有效修复、双策略互补和调度空间。全部复用已分析过的 20 个 DocRED 开发文档、10 个文档对、407 条候选；原始生成 40 包中 38 包非空，另两包不调用。不是新测试集、自然错误实验或独立确认性证据。参考图构造的输入含 226 个参考事实和 28 个注入项；参考及注入身份不提供给核验模型。

当前主 RL benchmark 仍是 TNEWS 自定义受控图（450 条新闻、873 节点、1,083 边）；本研究不替换它，也不声称已有生成规则参与的正式 DDQN 结果。

## 核验语义与 schema

- 先复核原引用、词表和不可变文档对上下文。自动判断另外标为 `automatic_review`，不会填入 `independent_review` 或旧 trusted registry。
- 所有候选包括许可和支持规则都检查。每条类型规则必须覆盖本对初始记录中全部匹配记录；无匹配或任意不确定则弃权。该类型判断仅对绑定的当前文档对有效；原环境只删除记录，不向新实体/新图外推。
- `supported` 要求精确的有向关系获来源支持；`contradicted` 要求明确否定或同关系、实体及时间范围的正面不相容证据。未提及、共同出现、其他关联及非排他关系的不同取值不构成矛盾。
- `allowed` 是类型兼容，不是事实成立；`forbidden` 是实际实体与关系语义不兼容，不以罕见组合或 MISC 等粗标签推断。
- 每项审批有逐字来源引用；程序核对文档、句号索引与引用存在，不把这些机械检查当作语义证明。
- 40 个类型关系的本地关系名称来自既有 DocRED 词表，保留数据来源与哈希。Wikidata 批量公开元数据直连超时，经代理 HTTP 403，均保存日志。不把无法取得的定义或例外写成已经核验。
- 当前没有经审定的 DocRED 粗类型至属性硬约束的完整映射。因此本轮 schema 为 **0 硬映射**，所有 schema 判断为 uncertain。schema-only 是覆盖诊断，不是已验证强基线；combined 与 automatic 可能完全相同。不得为制造增益补写手工允许/禁止列表。

## 请求与输出

唯一模型 `Qwen3.8-27B-no-thinking`；温度 0，输出上限 6,000 tokens。38 个任务，每个非空候选包一次核验，包含两篇原文、公开实体/记录、关系名称和全部候选。无 GPT/Claude、模型回退或本地模型下载。

输出仅有 `decisions` 数组，逐候选 `ordinal` 对应 `checks`；每个匹配记录包含 `record_id, verdict, rationale, evidence`。判断为 approve/reject/uncertain；简短理由最多 240 字符；证据最多两处，批准必须有证据。逐候选、逐记录的数量与顺序固定；重复键、缺失记录、额外字段、非精确引用、截断和非 stop 输出整包失败，相关候选全部弃权。不给模型补修 JSON 的机会。

每任务至多两次请求尝试，仅运输故障与 HTTP 429/500/502/503/504 重试；38 个任务实际最多 76 次尝试，另有总预算 80 次的硬上限。串行、间隔 3 秒，连接超时 15 秒、读取超时 150 秒，绕过代理且不跟随重定向。连续两个最终运输/协议失败或任意返回模型不匹配后设置持久停止标志，禁止自动重启批次。

请求前落盘派发意图；未知送达记 interrupted，不自动重发。所有失败、重试和未知送达保留，完成任务不重复调用。当前无可核实实时价目，美元金额留空；记录真实 usage、缺失 usage 数和耗时，不能把缺失 usage 写成零消费。

## 五组比较与评分

五组为 grounded、independent_empty、schema、automatic、combined。联合规则为：可靠 schema 或模型批准可准入，但任何明确拒绝都否决；没有依据的 uncertain 本身不否决另一有效批准。可靠 schema 本轮为空。准入规则仍需获取所属响应包后才激活。

每组用既有八种固定策略和十个文档对回放，共 400 条；同时枚举全部可行路径。随机策略保持原单个种子，不冒充多种子统计。核验和轨迹构建完成后才打开 scorer 文件；原始 80 条轨迹必须与存档逐项相同。

报告分类型规则数量、自动批准/拒绝/弃权、格式失败、激活数、F1、参考保留率、参考损失、注入移除、来源规则必要移除、单策略独有移除、核验阻止的旧误删与失去的旧有效编辑。以十文档对为单位、固定种子 20261004、10,000 次 bootstrap 给出相对 stop 和 grounded 的配对 F1 区间，仅作开发诊断。

沿用原恢复标准（同一个固定策略 F1 改善、平均保留至少 99%、至少两对有来源必要修复）、互补标准（两策略各至少一项安全独有移除，单策略零参考损失）及调度标准（安全 oracle 比最强固定策略至少高 0.5 点，或同等安全质量平均少一包且至少两对节省）。原生成格式 39/40 单独报告，不拿它冒充本轮模型核验成功率。即使诊断通过也不自动扩训。

核验调用与原 40 次生成调用分列；离线获取包数不等于实际在线节省。人工审查由作者安排，无人工结果时不报告核验语义准确率。

## 服务失败分支与交付

若服务触发停止条件，保留已请求结果，完成 grounded、independent_empty、schema 三组的 240 条离线回放；automatic/combined 明确标为未评估，不能把没有得到响应当成自动核验效果为零。保留 400 回放合成空核验 dry-run 为工程检查，不混入真实实验结果。本协议不在故障后自动改模型、重试新批次或改变样本。

归档代码、协议/请求哈希、脱敏判定、回放、成本、失败与报告；原始文本/响应留在忽略的 local/。结果确认后在 paper2 中同步报告、数学与实验说明、论文相关 sections、表格及编译检查。保留模板及作者自行维护的 Overleaf 格式；提交并 push 本轮文件。
