\section{Experiments}
\label{sec:experiments}

\subsection{Evaluation Design}
\subsubsection{Research Questions}
\label{subsubsec:evaluation_questions}
We ask three main questions. \textbf{RQ1:} How does a learned co-optimization policy compare with feasible-action schedules and a simple adaptive heuristic? \textbf{RQ2:} Which observation features and training components affect its decisions? \textbf{RQ3:} What do the two generation strategies contribute at equal call budgets, and which archived candidates can execute on a labeled suite? Additional structural and extraction tests describe the behavior of the repair layer.

\subsubsection{Data and Protocol}
\label{subsubsec:testset}
The policy environment uses 450 balanced TNEWS/CLUE documents, 30 per category, to build a graph with 873 nodes and 1,083 relations. Ten scenario seeds control isolation, duplication, invalid-relation, and dangling-edge corruption. The separate 180-case calibration inventory supplies online validator precision and recall. Rule acquisition activates registered modules; relation restoration uses the environment's private source record after a validator detects an invalid relation.

The rule study replays 9,456 successful archived responses, with deletion and augmentation responses for each of 4,728 government-service documents. RuleTest-94 supplies 30 clean and 64 defective records with stored expected outcomes. It is a designed test suite. A deterministic repair test uses 3,000 TNEWS titles, and an earlier API extraction test uses another recorded 45-title sample. These tests measure different parts of the implementation.

\subsubsection{Reproducibility}
\label{subsubsec:runtime_reproducibility}
The mathematical revision preserves the original environment and all earlier checkpoints. It freezes a corrected environment with violation-identity accounting, retrains DQN, Double DQN, and four ablations (sixty models), and archives all 110 evaluation trajectories. Training uses ten seeds and 250 episodes per model. Evaluation reuses the ten original scenarios, allowing paired follow-up comparisons. All new runs make zero API requests. The earlier extraction test used Qwen3.8-27B-no-thinking; the rule archive's historical decoding metadata is described in Appendix~\ref{app:prompts}.

\subsection{RL Co-optimization on Executable Graph Transitions}
\label{subsec:rl_results}
\subsubsection{Matched Policies and Measures}
Random, alternating, and rule-first schedules now select only feasible actions. They receive the same observation and mask as the learned methods. The stronger \emph{acquire-then-deficit} heuristic acquires missing high-precision modules in mixed, deletion, then augmentation priority. Once all four are active, it selects the feasible graph action with the largest weighted current quality deficit, using the weights in Equation~\ref{eq:kg_quality}. It reads no private corruption record and probes no transitions. This is a fixed observation-based heuristic, with no fitted thresholds.

A separate model-informed lookahead policy clones the environment and evaluates feasible one-step transitions before acting. We report its probe count to distinguish this information advantage. A one-step choice is not an upper bound on finite-horizon performance.

Final joint quality and common-budget trajectory quality are
\begin{equation}
\begin{aligned}
\bar Q_t&=\frac{Q(G_t)+0.4Q_{\mathrm{online}}(R_t)}{1.4},\\
\mathrm{AUC}_{18}&=\frac1{18}\sum_{t=0}^{17}\frac{\bar Q_t+\bar Q_{t+1}}2.
\end{aligned}
\end{equation}
An early terminal score is carried forward through step 18. All policies share this horizon and objective. Calls denote acquisition cost units in the environment; actual API requests are zero. Invalid actions, graph edits, rule edits, environment probes, and local elapsed time are recorded separately. The new AUC definition replaces the earlier archive's duration-normalized trajectory average for the matched comparison.

\subsubsection{Policy Results}
With the corrected reward, Double DQN reaches mean final quality 0.96855 and AUC 0.94514, using 6.2 accounted calls. The acquire-then-deficit heuristic reaches 0.98248 and 0.95797 with four calls. Full Double DQN minus the heuristic gives differences of $-0.01392$ and $-0.01283$; both Holm-adjusted $p$ values are 0.0195 (Table~\ref{tab:offline_tests}). Standard DQN reaches final quality 0.96920.

The reward now charges for introduced violations. Double DQN introduces none on these ten evaluation runs, while the heuristic introduces 4.8 per run on average. For $\mathcal R=\sum_{t=0}^{T-1}0.95^t r_t$, the mean discounted returns are 0.3660 and 0.3508, respectively. These descriptive measures show why final structural quality and the training objective give different rankings: avoiding newly introduced violations can leave some existing defects unresolved. We report both, rather than replacing the quality comparison with return. All reward components and introduced identities are retained for each transition.

\subsubsection{Retrained Ablations}
We train ten models for each of four variants, using the original 250 episodes per seed. The variants remove explicit graph features, explicit rule features, the action mask, or the acquisition-call penalty. Feature removal applies during both training and evaluation. The mask remains in the feature ablations and can convey rule availability. The no-mask variant removes masking from action selection and Bellman targets. The no-call-penalty variant changes only the training reward; evaluation uses the same corrected reward and cost coefficients for all settings.

\input{tables/math_revision_ablations}
\input{tables/math_revision_tests}

Removing the mask lowers final quality to 0.94800 and produces 10.7 invalid actions per run. Its final-quality contrast passes Holm correction ($p=0.0195$); its AUC contrast does not ($p=0.8340$). The graph-feature, rule-feature, and call-penalty contrasts do not pass the ten-test correction. Thus the revised results support the action mask's contribution to final quality, while the other independent gains remain unestablished in this environment.

The analysis enumerates all $2^{10}$ sign assignments for exact two-sided paired randomization tests and applies Holm correction across ten contrasts: full Double DQN against the heuristic and four ablations, for both metrics. Pointwise intervals use 10,000 paired bootstrap draws. The sixty new models contribute 15,000 completed training episodes. Earlier checkpoints and results remain archived under their original environment version.

\subsection{Dual-Strategy Candidate Generation}
\label{subsubsec:dual_strategy_ablation}
\subsubsection{Same-Document and Equal-Call Comparisons}
On the full paired archive, deletion yields 32,955 distinct categorized candidates, augmentation yields 41,683, and their union contains 71,656. These totals include entity and relation declarations. The union is 71.9\% larger than augmentation alone but uses twice as many calls: 9,456 versus 4,728. It measures additional candidate coverage on the same documents.

To compare candidate diversity at equal cost, we fix call budgets of 100, 500, 1,000, 2,000, and 4,000. For each of thirty seeded permutations of the paired document inventory, a single strategy processes $B$ documents once each; the dual strategy processes the first $B/2$ documents with both strategies. Thus call count is matched while document coverage differs. Canonical aggregation follows the archived code, with declarations separated from constraint candidates. Table~\ref{tab:equal_budget} gives representative budgets; all budgets and samples are released.

Augmentation produces more distinct constraint candidates than the dual strategy at every matched budget. At 1,000 calls, the means are 7,787 versus 7,126. Candidate correctness is evaluated separately from diversity.

\subsubsection{Provenance-Based Execution Audit}
\label{sec:rule_execution_audit}
The archive contains 181,851 candidate occurrences. Exact allowed/forbidden type patterns compile to 18,143 distinct rules, retaining the document, strategy, response line, category, and ordinal of each occurrence. Only two distinct compiled patterns match any RuleTest-94 record. Of 32,360 compilable occurrences, 32,348 contain vocabulary absent from the relevant suite positions, nine use represented vocabulary but match no record, and three match a record. This exposes a schema-alignment gap between the source archive and the test suite.

\input{tables/offline_execution}

Direct execution of the union detects 10 of 64 defects and flags none of the 30 clean cases, giving recall 0.156 and F1 0.270. Augmentation alone makes no positive prediction, so its precision is undefined. Allowed patterns act as permissions rather than a closed-world whitelist; conflicting permissions and prohibitions cause abstention. No conflicts occur on this suite. Unsupported and malformed candidates remain in the audit counts and provenance files. Each strategy is scored on all 94 test cases.

\subsubsection{Generated Rules in an Offline Repair Loop}
\input{tables/math_revision_bridge}
The bridge in Section~\ref{sec:rule_bridge_method} activates the exact archived typed patterns on RuleTest-94, recomputes detections and the removal-action mask, executes allowed removals, and records the next state. Deletion activates 5,794 patterns, augmentation 12,617, and their union 18,143. Deletion and the union each remove ten defective records and no clean record; augmentation changes no record. Synthetic interface tests additionally check conflict abstention, malformed candidates and unsupported families without adding those probes to the empirical sample count.

\subsection{Runtime and Cost Accounting}
\label{subsec:runtime_cost}
The original twenty-model RL run recorded 1,278.99 seconds of CPU time with zero API calls. The sixty corrected-environment runs also make zero requests; their per-run durations and all evaluation timings are archived. Evaluation timing covers policy inference and environment transitions, excluding environment construction. Model-informed lookahead additionally includes cloned transition probes. These local timings do not estimate LLM latency.

The earlier 45-document extraction test made 45 actual calls and recorded 1,190.90 seconds. The rule archive records 9,456 successful responses; historical latency, tokens, retries, and failed requests are not fully recorded. Equal-call candidate comparisons therefore measure diversity per archived successful call, rather than total billed cost. The environment's acquisition units model that cost during scheduling.

\subsection{Scope and Next Evaluation Steps}
The controlled environment gives exact graph mutations and reproducible rewards, but its fixed validator inventory and regular acquisition effects make a simple heuristic effective. The learned policy's usefulness in more varied repair settings remains to be tested with independently collected trajectories.

Generated typed rules have limited direct overlap with RuleTest-94. A validated vocabulary mapping and execution support for additional rule families are needed before those candidates can replace the registry inside the RL loop. The offline bridge provides rule-to-action traces on the designed suite; the remaining integration must evaluate learned scheduling with generated-rule arrivals and broader repair operators. Natural-defect annotation and held-out domains would then test semantic correctness and transfer. The present extraction labels support category and keyword indicators rather than gold triple accuracy.
