# 工具脚本

| 目录 | 用途 |
|---|---|
| `converters/` | JSONL、CSV、Neo4j 格式转换 |
| `data_generation/` | 数据准备与缺陷生成 |
| `monitoring/` | 结果检查与进度监控 |
| `maintenance/` | 仓库文件、依赖和论文交付核对 |

论文构建工具在 [Paper1 tools](<../paper1 merge/tools/>) 和 [Paper2 tools](../paper2/tools/)。实验脚本仍在 [exps/](../exps/README.md)。本目录的 `crawl.py`、`sports*.py`、`rules.py` 是原有数据工具。
