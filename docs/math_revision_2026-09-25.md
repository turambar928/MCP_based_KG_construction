## 2. Paper1：哪些数学问题得到修复

### 2.1 空值与关系方向

来源支持要求值非空且出现在来源中。旧诊断利用 `'' in source` 的 Python 行为，可能漏报空值；新诊断明确拒绝空串与纯空白。已有回放输入中，该修正未改变任何诊断，因此不能据此宣称主结果提高。

管理、监管采用上级到下级的方向，隶属于采用下级到上级的方向。仅对明确行政后缀判断等级，避免把“自治区”的“区”当作县区等级；“上级”等含义不明确的关系不推断反向。

### 2.2 节点集合与实体引用

图中出现的所有端点可以用于拓扑统计，但不能又把该集合当作“已声明实体表”检查悬空端点。新增 `TaskContext` 区分两者：

- `document_node`、`allowed_relations` 是公开任务约束；
- `declared_entities` 是实体引用的声明集合；
- `entity_endpoints` 指定 `head` / `tail` 哪些端点是实体引用。

未提供实体引用类型时按开放世界处理。字符串字段值不会因为不在实体声明表中而被删除。单操作和组合操作统一检查非空图保护。

### 2.3 共享特征，不再以 gold 推断缺失

八维输入仍为四个质量分数、节点数、边数、简单有向投影密度、违规条目数。训练与运行时调用同一 `assess` 实现。

旧训练中的 `S_iso` 实际是相对 gold 关系集合的完整性，而运行时表示非孤立节点比例。新版统一为后者；训练脚本也不再用另一套计数覆盖 `n_viol_feat`。模型与缩放器携带 `public-profile-v2` 版本，旧权重被拒绝并显式回退到均匀先验。

公开文档节点标识沿用已有协议：原始文件把它存放在参考图首个主体中，构建时将该标识物化为任务元数据。参考关系、参考尾值和缺陷标签不进入特征计算；clean 行的图本身当然作为该行输入。反事实测试修改参考值、参考关系和缺陷标签，公开输入、特征与运行决策不变。

### 2.4 缺失提示与停止条件

仅从来源中的显式字段标签及非空值构造补充候选。关系白名单不代表所有关系必填。同标签出现冲突值时不自动补充。

显式来源字段缺失进入违规计数；已有建议候选也会绕过“低修复概率”和“没有违规”的提前停止，获得实际试算。候选仍要通过质量约束及正效用判定。

**没有增加一个隐藏的完整性目标。**部分星形图仍可能获得四项质量满分；新版消除了未经评估就停止的问题，并未证明所有来源字段都会补齐。均匀默认方案的受控试算从旧版 220 次增加到 471 次，接受数仍为零，说明剩余瓶颈是效用阈值。

### 2.5 效用、先验零点与保证

默认效用为：

$$U(a)=\frac{\Delta Q}{100}+0.20\frac{\max(0,h-h')}{\max(1,h)}-0.35c(a)+0.05\log(\max(\pi_s,0.05)+10^{-6})+0.02z(a).$$

固定对照减去常数 $0.05\log(1/3+10^{-6})$。均匀先验因此恰好贡献零；同一状态下候选排序不变，但正效用接受边界改变。系数未根据测试表现搜索，默认仍用原绝对对数项。

学习路由的相对零点在受控输入上使 F1 从 84.72% 变为 89.29%，自然输入从 87.99% 变为 87.64%。均匀路由两种公式输出相同。不能据受控提升将相对零点宣布为全面改进。

局部质量下界、每维至多两点回退、密度及非空约束，不构成全局 F1 单调性或语义正确性证明。主 gate 的最大保留数量性质继续只针对独立容量为一的关系组。来源字面匹配也不能证明字段含义匹配。

### 2.6 神经网络与复杂度

重训保持 8→32→16→(1+3)、884 参数、种子 42、原文档分组和训练预算。缩放仅拟合训练集。受控测试上的修复判别与主尺度分类均为 100%，属于对注入缺陷的监督识别；网络不是 RL 训练的价值函数。

主 gate 的候选扫描与顺序优化器分开计复杂度。后者的两两冗余检查为 $O(m^2)$，$T$ 轮、每轮 $K$ 个试算图对应 $O(TKm^2)$，另计来源字符串处理。

## 3. Paper2：奖励、观测与 RL

### 3.1 新增违规按身份计算

新版定义：

$$N_{new}=|\mathcal V(G_{t+1})\setminus_m\mathcal V(G_t)|.$$

节点用稳定 ID，边的每个出现有独立 ID，重复边也不合并掉。违规身份包含种类与对应记录；用多重集差集计数。仅用 `max(0,after_count-before_count)` 会漏掉“修一个、引入另一个”的情况。

反例中，删除 `d→missing` 消除悬空边，却令 `d` 孤立。违规总数不变，新版仍计一个新违规，将该步奖励从约 0.04998 调整为 0.03998。所有评估轨迹记录新违规身份及四个奖励分项，分析脚本逐条验证其和等于总奖励。

空可行动作集结束回合，训练自举项为零。清空非空节点集或边集的操作回滚，并记录终止原因。

### 3.2 保留 RL，不把聚合观测包装成充分状态

14 维向量与网络结构保持不变，避免把观察表示变化混入奖励修复。Coverage 与有效规则比例在当前 registry 中重复；正文明确说明。

相同 14 维观测及掩码的两个图，执行同一悬空边删除动作后，可以产生不同的新孤立点和奖励。因此完整环境状态可建模为 Markov 状态，但聚合观测的充分性没有证明。DDQN 使用该观测近似价值函数，不改变其训练框架。

### 3.3 折扣目标并非只有终点

令 $J_t=Q(G_t)+0.4Q_R(R_t)$：

$$\sum_{t=0}^{T-1}\gamma^t(J_{t+1}-J_t)=-J_0+(1-\gamma)\sum_{t=1}^{T-1}\gamma^{t-1}J_t+\gamma^{T-1}J_T.$$

所以 $\gamma=0.95$ 时，策略也偏好较早取得质量提升。正文保留真实的 target 同步周期、探索率衰减和成本计数；模拟调用单位不写成实际 API 请求。

固定校准规则库的最高规则分数约为 0.940862，相应联合分数上界约为 0.983103。这是该评分系统的代数上界，不是 18 步内一定可达，也不是事实准确率。

### 3.4 离线重训和统计

新版重训 DQN、DDQN 和四项消融，每项十个种子、每次 250 回合、18 步上限。原有四个可行策略与 model-informed lookahead 全部在新版环境重新评估。十场景配对、统一 18 步 AUC、10,000 次 bootstrap 和十项 Holm 校正保持原协议。

60 个模型和 110 组评估全部完成。新版 DDQN 最终质量为 0.96855、AUC 为 0.94514、平均计账调用 6.2；强启发式分别为 0.98248、0.95797、4.0。两项质量差异的 Holm p 均为 0.0195。DDQN 在十场景中新增违规为零，强启发式平均 4.8；平均折扣回报分别为 0.3660 与 0.3508，作为描述性补充指标报告，不替换预定的质量比较。

该变化解释了为何必须重新训练：惩罚真正生效后，策略倾向于避免引入新违规，即使保留部分旧缺陷。去动作掩码的最终质量差异仍显著；图特征、规则特征和调用成本的独立增益没有通过十项校正。论文已更新旧优势结论，未按结果调整惩罚系数。

## 4. 生成规则闭环原型的实际范围

原型把历史候选编译为精确类型规则，按 deletion、augmentation 或两者并集激活，重算违规与删除动作掩码，再执行并重算。每条匹配保留规则 ID 和来源。运行器不读取标签、不猜测 TNEWS 类型映射，也不推断替代事实。

在已检查过的 RuleTest-94 上：

| 规则包 | 激活规则数 | 删除缺陷记录 | 删除干净记录 | 剩余记录 |
|---|---:|---:|---:|---:|
| Deletion | 5,794 | 10 | 0 | 84 |
| Augmentation | 12,617 | 0 | 0 | 94 |
| Union | 18,143 | 10 | 0 | 84 |

全部 30 条干净记录保留。这里只证明实际存档规则可以改变检测、动作权限和记录集合；删除十条违规记录不等于恢复十条正确事实。该原型使用固定调度，不提供“生成规则接入后 RL 更优”的证据。冲突弃权、无法编译、无匹配分别有接口测试，合成测试不并入 94 条经验分母。
