# Paper 1 方法图内容修正与美化（2026-09-24）

保留三张原图的整体构图、图标风格与模块配色，更新可编辑 SVG 和正文使用的矢量 PDF。原始 PNG 留作设计参考。本轮不调用模型 API，也不修改实验代码、预测或人工标注材料。

## 内容修正

|图|修正|
|---|---|
|图 1：整体架构|用 Non-isolated nodes、Rule consistency、Source support 对应实际计算；取消修复提供方与三个尺度的一一绑定；明确候选试算、每轮选择一个最高正效用的可行编辑；反馈回到评估模块。|
|图 2：诊断尺度|三个视角并列汇入同一报告；移除 expand 和逐级扩大范围的箭头；将 Hierarchy 限定为显式规则；来源检查表述为值与原文的匹配。|
|图 3：顺序选择|补齐低概率下硬违规仍触发检查的条件；没有检测到违规则停止；展示固定模型编辑包与规则候选；明确每轮选择最高效用的可行正效用编辑；反馈从提交后的图出发。|

图 3 的停止条件对应 `content_enhancement/constraint_optimizer.py`：

1. 修复概率低于阈值，且不存在硬违规；或
2. 没有检测到违规；或
3. 没有可行且效用为正的候选；或
4. 达到迭代上限。

删除、关系改写、补全的固定操作代价为 0.30、0.16、0.06。它们是效用函数中的惩罚系数，不是 API 价格；编辑包的代价累加其子操作。

正文同步解释四个图中符号：非孤立节点比例 `Q_inc`、唯一性 `Q_uniq`、规则一致性 `Q_rule`、来源支持 `Q_src`。图 1 与图 3 展示单独评估的顺序选择模块；主要基准的单次模型调用与过滤流程继续按正文算法描述。

- 图 1 保留五列架构，统一卡片与留白，减少重复模块。
- 图 2 保留三个圆形视角，以汇合线代替扩展箭头。
- 图 3 保留左侧诊断、中间策略、右侧提交的布局；步骤编号与运行顺序一致，约束参数单独作为试算输入。
- 使用 Times New Roman，统一标题层级、线宽、浅色背景与直角连接线。
- SVG 保留可编辑文字；PDF 使用矢量文字和路径。二者从相同绘图源生成，避免分别编辑导致内容漂移。

生成命令：

```bash
python3 paper1/make_method_figures.py
cd paper1
tectonic -X compile main.tex --keep-logs
```
