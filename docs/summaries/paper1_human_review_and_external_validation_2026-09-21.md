# Paper 1 真人标注交付、独立文本验证与行文修订

## 本轮交付

1. 为两位真人各准备 400 条独立标注材料：D 输入差异 200 条，E 实际修改 200 条。样本沿用原冻结集合，没有重新抽取。
2. 每人有独立 ZIP，内含 HTML 离线页面、Excel 表格、中文详细说明（MD 与 HTML）。说明涵盖定义、流程、例子、U 的使用、重复与替换操作、备份和交付。
3. 协调员另有说明与方法映射；收回脚本支持 JSON/XLSX，校验身份、ID、完整性、0/U 理由，裁决前保留原始标签并计算一致率。裁决阶段检查原标签及上下文是否被改动。
4. 补充 SROIE 独立文本验证：固定抽取 60 张收据的转录文本，另行读取公开人工字段标签。使用 Gemma 提取并比较 base、diagnostic、SHACL 三种修复上下文；每次响应同时评估 raw/gate。
5. 简化论文摘要、引言、方法、实现、相关工作、实验和结论。正文介绍最终方法，不反复回顾版本错误；结果段直接列数据，适用范围与局限集中为一小节。

## 独立验证协议

使用 SROIE 社区修正版 trainval 镜像（626 个文档），固定提交
`27be4271b251c256f695acbade9a801bffe85994`，随机种子 20260922，60 个样本在调用前冻结。只下载文本与标签，没有下载模型或图片。

输入为文本框转录按原存储顺序拼接的文本，标签来自另存的 KIE 文件；没有由标签反向构造来源。公开 schema 为 company/date/address/total。一个样本缺少 address 标注，该项仅在评分时排除，模型仍看到全部四个可用字段，共评价 239 个有标注字段。

主指标是逐文档严格三元组 F1 与全图匹配；辅助指标仅在评分时忽略值的大小写和空白。全部配置共 60 次提取、180 次修复输出；失败也保留。模型为 `google/gemma-4-26B-A4B-it`，没有 GPT/Claude 新调用。

修复调用前修正了一处 SHACL 上下文准备问题：收据中的 SERVICE 被校验器误识别为查询关键字。现在通过 RDF 数据绑定来源，而非把原文嵌入 SPARQL 查询；变更记录保留在 `protocol_amendment.json`，没有更换样本或重跑抽取结果。旧机制实验与 hash 保持不变。

完整数据、协议、预测、逐例分数和复现命令位于 `exps/paper1_external_receipts/`。

## 行文调整原则

- 将抽象名词和长从句改为直接动词与较短句子，统一用 input、source、candidate、filter 等术语。
- 删除摘要、引言、方法和结论之间重复的“不能证明”“不应声称”“尚不足以”等句式。
- 保留实质事实：字段复制基线满分、匹配实验中的负结果、不同来源和参考类型、真实人工复核待完成。
- 把历史执行路径和撤回旧结论的过程留在技术审计文档。论文分别介绍单次候选过滤与顺序选择器，避免把两者混为一个实验方法。
- 外部实验单独报告，不把小样本结果表述为跨领域普遍保证。

## 尚待真人完成

两位标注者独立填写并交回文件，协调员再进行裁决。相关脚本、材料和说明已就绪，当前不报告虚构的 kappa 或人工接受率。SROIE 自带人工标签与这轮待完成的独立复核分开表述。

## 完成后的外部结果

240 次请求均成功解析。初始提取严格 F1 为 79.44%；基础、诊断、SHACL 三种提示加原过滤器分别为 79.15%、79.15%、79.56%，全图精确匹配均为 33.33%。本次独立文本测试没有显示稳定的修复增益，论文按实测结果报告。

3 次候选拒绝对应同一个地址在三种配置中出现：来源有双空格，而 JSON 解析器把候选中的空白合并了。另做不调用模型的空白一致性检查，来源采用相同空白合并后保留该正确地址；三种配置 F1 分别为 79.44%、79.44%、79.86%。主实验表保持原协议，空白检查作为事后分析单独报告，没有替换原结果或在测试集上选出新的主方法。

新图：`paper1/figure/experiments/external_receipts.pdf`。PDF：`paper1/main.pdf`。所有活动图仍为 Times New Roman 矢量 PDF。表格、图片和摘要/结论可由归档结果重新生成。

排版检查还修复了 Springer 模板的摘要调用方式：将 abstract/keywords 定义移到 maketitle 之前，并使用类文件要求的 abstract 参数形式，解决摘要首字母丢失、Abstract 标题和关键词未显示的问题。
