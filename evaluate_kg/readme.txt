# 知识图谱质量评估工具

这是一个用于评估Neo4j知识图谱质量的Python脚本，支持从CSV文件加载图谱数据，并进行多维度质量评估，最终生成详细的质量报告和质量评分。

修改流程部分的质量评估函数，评估为neo4j的三元组形式

## 主要功能

- **孤立节点检测**：识别未参与任何关系的节点
- **冗余三元组检测**：发现重复的三元组关系
- **逻辑一致性检测**：根据自定义规则检查节点类型和关系类型的逻辑冲突
- **语义一致性检测**：使用智谱AI大模型评估三元组的语义合理性
- **综合质量评分**：生成标准化的质量评分报告（0-100分）

## 安装与使用

### 依赖安装

```
pip install pandas numpy zhipuai
```

### 配置说明

在脚本顶部修改`CONFIG`配置参数：

```
CONFIG = {
    "node_files": ["./nodes.csv"],          # 节点CSV文件路径列表
    "relationship_files": ["./relationships.csv"],  # 关系CSV文件路径列表
    "zhipuai_api_key": "YOUR_API_KEY",      # 智谱AI API密钥
    "zhipuai_model": "glm-4",               # 智谱AI模型名称
    "output_dir": "./qa_report",            # 报告输出目录
    "semantic_eval_sample_size": 0.1,       # 语义评估采样比例(0-1)
    "logical_rules": {                      # 自定义逻辑规则
        "不允许的节点类型": ["Unknown"],
        "无效关系类型": ["NONE"],
        "类型冲突规则": {
            ("用户", "购买", "水果"): "允许",
            ("用户", "购买", "用户"): "禁止"
        }
    }
}
```

### 运行脚本

```
python kg_quality_eval.py
```

### 输入文件

1. **节点文件** (nodes.csv)
2. **关系文件** (relationships.csv)

## 输出结果

脚本运行后，在输出目录(`./qa_report`)中生成以下文件：

1. **报告文件**：
   - `report.txt`：包含详细评估结果和质量评分
   - `quality_scores.json`：各维度得分和总分的JSON格式
2. **问题数据文件**：
   - `isolated_nodes.csv`：孤立节点列表
   - `redundant_triples.csv`：冗余三元组列表
   - `logical_conflicts.csv`：逻辑冲突列表
   - `semantic_evaluation.csv`：语义评估结果
   - `all_issues.csv`：所有问题三元组汇总
3. **质量评分文件**：
   - `quality_scores.json`：包含各维度得分和总分

## 质量评分系统

评估系统基于四个维度计算质量得分，每个维度权重为25%，满分100分：

1. **节点连通性**：基于孤立节点比例计算

   ```
   得分 = (1 - 孤立节点比例) × 100
   ```

2. **三元组唯一性**：基于冗余三元组比例计算

   ```
   得分 = (1 - 冗余三元组比例) × 100
   ```

3. **逻辑一致性**：基于逻辑冲突比例计算

   ```
   得分 = (1 - 逻辑冲突比例) × 100
   ```

4. **语义合理性**：基于语义一致性平均分计算

   ```
   得分 = 语义一致性平均分 × 100
   ```

**最终质量得分**：

```
总分 = (节点连通性得分 × 0.25) + 
       (三元组唯一性得分 × 0.25) + 
       (逻辑一致性得分 × 0.25) + 
       (语义合理性得分 × 0.25)
```

## 自定义配置

### 逻辑规则配置

在`logical_rules`中自定义规则：

```
"logical_rules": {
    "不允许的节点类型": ["Unknown"],  # 禁止使用的节点类型
    "无效关系类型": ["NONE"],        # 禁止使用的关系类型
    "类型冲突规则": {                # 特定类型组合的规则
        ("Person", "购买", "Product"): "允许",
        ("Person", "购买", "Person"): "禁止"
    }
}
```

### 语义评估配置

- `semantic_eval_sample_size`：控制用于语义评估的三元组采样比例
- `zhipuai_model`：指定使用的智谱AI模型（如glm-3-turbo, glm-4等）

## 注意事项

1. 确保提供有效的智谱AI API密钥
2. 节点文件必须包含ID列（可自定义列名）
3. 关系文件必须包含起始节点ID、结束节点ID和关系类型
4. 语义评估部分可能需要较长时间，建议先使用小样本测试
