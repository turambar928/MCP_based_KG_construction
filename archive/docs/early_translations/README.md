## 如何阅读公式和图片

使用支持 LaTeX 数学的 Markdown 阅读器，例如启用数学支持的 Typora、VS Code Markdown 预览，或 GitHub 的 Markdown 页面。行内公式使用单美元符，独立公式使用双美元符；公式没有放入普通代码块。纯文本编辑器会显示公式源码，这是正常情况。

两份 Markdown 的正文和公式可独立阅读。要显示插图，请将 `assets/` 与两份 `.md` 放在同一目录，或者直接下载并解压上述 ZIP。图片由当前英文稿引用的 PDF 图表转换而来，保留原图英文标签，配有中文图注。压缩包不包含 PDF。
